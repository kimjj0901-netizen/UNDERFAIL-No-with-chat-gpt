# 08 — 화면 전환과 컷신 연출

## 1. 전환 유형
- Hard cut: 의미가 명확한 즉시 전환.
- Fade in/out: 장면·시간 전환.
- Camera pan: 인물이나 오브젝트 강조.
- Scale emphasis: 중요한 대상에 시선 집중.
- Pose pause: 움직임을 잠시 멈춰 감정 전달.
- UI reveal: 대화창이나 전투 메뉴를 필요한 타이밍에 등장.
- Sound bridge: 장면이 바뀌어도 소리의 흐름으로 연결.

## 2. 시각 참조 원리
오프닝 이미지·전투 스크린샷은 화면 전체의 효과보다 한 장면의 정보와 시선 집중이 중요함을 보여준다. 긴 연출만이 아니라 한 순간의 정지, 프레이밍, 짧은 문장도 연출의 일부다.

## 3. UNDERFAIL 오프닝 적용
[기초자료 확인] 폐교 확인서에 도장을 찍는 인물의 얼굴은 초반에 드러내지 않는다. 손·소매·도장만 보여 주는 제약을 유지한다.

[제안]
- 과거 학교의 활기 → 문서의 정적 → 현재 학교의 차가운 여백으로 시각적 리듬을 만든다.
- 도장 소리 전후에 짧은 무음을 사용한다.
- 꽃밭에서 불리가 접근할 때 화면을 과도하게 흔들지 말고, 거리와 시선으로 긴장을 만든다.
- 도미토리엘 구출에서는 추상적인 보호 효과와 캐릭터의 등장 타이밍을 함께 설계한다.

## 4. 기술 구현 규칙
- 전환 중 입력을 잠근다.
- 타이머와 Tween은 Scene 종료 시 정리한다.
- 같은 입력으로 전환이 두 번 실행되지 않게 한다.
- 텍스트/화면/소리가 같은 스토리 이벤트를 참조하도록 한다.
- 전환 연출이 실패해도 다음 Scene으로 진행할 수 있는 복구 경로를 둔다.

## 5. 검증
실제 플레이 중 화면이 갑자기 바뀌는지, 스토리 정보가 충분히 이해되는지, 플레이어가 조작을 되찾는 시점이 명확한지 확인한다.
