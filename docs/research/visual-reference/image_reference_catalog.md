## 추가 이미지 조사
다음 작업에서 방별·캐릭터별·보스별 참조를 더 추가할 수 있다. 특정 이미지는 반드시 원출처 페이지까지 확인하고, 저작권 및 사용 범위를 기록한다.

## 사용 규칙
- 연구 문서에 외부 링크 및 제한된 미리보기로만 사용.
- 최종 게임 자산에 포함하지 않음.
- 원작 화면을 그대로 재현하는 개발 지시로 사용하지 않음.
