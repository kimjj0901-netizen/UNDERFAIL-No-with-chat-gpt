# UNDERFAIL 시각 참조 연구 — 안내

## 목적
Undertale의 타이틀, 오프닝, 방, 전투, 캐릭터, UI 스크린샷을 분석해 화면 구성·정보 위계·애니메이션·시선 유도 원리를 찾는다. 이 자료는 UNDERFAIL의 독자 디자인을 위한 참고 연구다.

## 문서 구성
- `01_GLOBAL_VISUAL_LANGUAGE.md`: 전체 시각 언어
- `02_TITLE_AND_OPENING.md`: 타이틀과 오프닝
- `03_OVERWORLD_AND_ROOMS.md`: 탐험 화면과 방
- `04_CHARACTER_DESIGN.md`: 캐릭터 디자인
- `05_BATTLE_VISUALS.md`: 전투 화면
- `06_UI_AND_TYPOGRAPHY.md`: UI와 글자
- `07_ANIMATION_AND_EXPRESSION.md`: 애니메이션과 표정
- `08_TRANSITIONS_AND_CINEMATICS.md`: 전환과 컷신
- `09_COLOR_PALETTE_AND_CONTRAST.md`: 팔레트·명암
- `10_UNDERFAIL_VISUAL_GAP.md`: 현재 프로젝트와 비교
- `image_reference_catalog.md`: 스크린샷·이미지 링크 색인
- `image_source_and_license_ledger.md`: 출처 및 사용 권리

## 분석 태그
- [이미지에서 직접 관찰]: 이미지·스크린샷에서 확인되는 시각 사실.
- [개발자 발언]: 제작자가 설명한 설계 의도.
- [분석]: 시각적 관찰을 기획 관점에서 해석.
- [UNDERFAIL 제안]: 사용자의 승인 전까지 정사가 아닌 디자인 제안.
- [검증 한계]: 단일 스크린샷만으로 카메라·히트박스·프레임 규칙을 단정할 수 없는 부분.

## 이미지 이용 원칙
원작 스크린샷은 링크와 제한된 분석용 미리보기로만 취급한다. 원작 스프라이트, UI, 배경, 음악, 폰트, 텍스트를 게임 자산으로 복사하지 않는다. 상업용 배포에 포함할 에셋은 직접 제작하거나 명확한 상업 라이선스를 확보한다.

## 한계
여기에 링크된 이미지는 특정 장면의 한 프레임이다. 이를 통해 전체 애니메이션, 내부 좌표계, 입력 타이밍, 모든 장면의 화면비를 증명할 수 없다. 실제 게임 관찰 자료가 추가되면 이 문서들을 갱신한다.
