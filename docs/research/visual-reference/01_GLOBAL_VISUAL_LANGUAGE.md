# 01 — Undertale 전체 시각 언어 분석

## 1. 관찰 프레임
Undertale의 시각 디자인을 “픽셀아트” 한 단어로 줄이지 않는다. 화면은 타이틀·오프닝·탐험·전투·대화 등 서로 다른 사용 목적을 가진 화면 유형으로 나뉜다. 동일한 게임 안에서도 각 장면의 정보량과 명암 배치는 달라진다.

## 2. 화면 유형별 위계
| 화면 유형 | 가장 먼저 읽히는 정보 | 보조 정보 | 시각적 역할 |
|---|---|---|---|
| 타이틀 | 게임 이름/시작 선택 | 배경·상태 변화 | 플레이 시작 전 정체성 |
| 오프닝 | 현재 전달하는 한 장면과 짧은 텍스트 | 어두운 여백·음악 | 세계관 정보를 장면 단위로 전달 |
| 탐험 방 | 이동 가능한 길과 주요 오브젝트 | NPC·배경 디테일 | 공간을 읽게 함 |
| 대화 | 화자·문장 | 표정·캐릭터 위치 | 정보와 감정 |
| 전투 | 적·플레이어 상태·현재 명령 | 공격 영역 | 현재 해야 할 일을 분명하게 함 |
| 적 턴 | SOUL과 회피 보드 | 적과 패턴 예고 | 시선과 조작을 한 영역에 집중 |

## 3. 이미지 참조에서 관찰되는 원리
- 타이틀 스크린샷은 로고와 배경을 읽는 공간을 확보한다.
- 오프닝 참조는 제한된 톤의 장면과 어두운 여백, 짧은 텍스트로 구성된다.
- 전투 참조는 적·회피 공간·하단 명령이 시각적으로 분리되어 있다.
- 단일 화면에 모든 정보가 동시에 강한 대비로 튀어나오지 않는다.

## 4. 개발자 발언과 연결
Toby Fox는 Undertale 전투 엔진을 다른 요소보다 먼저 만들었다고 설명하며, 짧은 탄막 패턴과 여러 적 공격의 조합을 전투 다양성의 기반으로 언급했다. 이는 시각 스타일이 단순 장식이 아니라 전투 행동의 가독성과 밀접하게 연결되어 있음을 시사한다.

## 5. UNDERFAIL 적용 제안
- [제안] 화면마다 주요 초점을 하나만 정한다.
- [제안] UI는 동일한 외곽선·여백·선택 강조 규칙을 공유하되 장면 목적에 맞춰 크기와 위치를 조절한다.
- [제안] 배경의 장식 밀도보다 이동 경로·조사 대상·대화 텍스트가 먼저 읽혀야 한다.
- [제안] 전투에서는 적 이미지, 대사, SOUL 영역, 명령 메뉴를 시각적으로 분리한다.
- [제안] 중요한 장면은 평상시 화면보다 큰 대비 변화를 허용하되, 지속적인 과장 효과는 피한다.

## 6. 그대로 복사하지 않을 것
원작의 고유 픽셀 실루엣, 폰트 형태, 로고, 화면 배치의 정확한 수치, 원작 UI 그래픽을 복사하지 않는다. 분석하는 것은 정보 위계와 화면 목적이다.

## 7. 검증 필요
이 문서는 대표 스크린샷 분석이다. 프레임별 애니메이션, 실제 색상 팔레트의 완전한 목록, 모든 방의 UI 위치·논리 좌표를 직접 계측한 자료가 아니다.
