# 07 — 애니메이션과 표정

## 1. 애니메이션을 분류한다
- Idle: 대기 중 미세한 호흡·흔들림.
- Walk: 방향별 이동 프레임.
- Turn: 이동 방향 전환.
- Interact: 조사 또는 대화 시작.
- Talk: 말하는 동안의 표정/몸짓.
- React: 놀람·당황·기쁨·실망 등.
- Battle: 전투 시작·행동·피격·후퇴.
- Cutscene: 스토리에서 중요한 한 번의 포즈/동작.

## 2. Undertale에서 배울 기능
작은 스프라이트와 제한된 프레임은 캐릭터가 항상 복잡하게 움직이지 않아도 대사·표정·타이밍의 조합으로 감정을 전달할 수 있다는 점을 보여준다. 단일 스크린샷으로 프레임 수와 정확한 FPS를 추정하지 않는다.

## 3. UNDERFAIL 현재 상태
기존 캐릭터 SVG는 정적 이미지이며, 일부 Scene에서 낮은 진폭의 Tween을 사용한다. 방향별 걷기 프레임이나 감정별 스프라이트 시트는 아직 부족하다.

## 4. 개선 제안
- [제안] 먼저 걷기/대기/방향 전환의 최소 세트를 제작한다.
- [제안] 감정 애니메이션은 대사와 연결된 표정 변경부터 구현한다.
- [제안] 특별한 장면에서만 큰 움직임을 사용한다.
- [제안] 같은 캐릭터는 화면마다 다른 임시 도형으로 다시 그리지 않고 공유 에셋을 재사용한다.
- [제안] 접근성 측면에서 빠른 점멸, 과도한 흔들림, 불필요한 카메라 줌을 피한다.

## 5. 프레임 제작/검증 표
| 애니메이션 | 방향 | 프레임 목표 | 상태 |
|---|---|---|---|
| Player idle | down/up/left/right | 프로토타입 테스트 후 확정 | 미정 |
| Player walk | down/up/left/right | 프레임 시트 제작 필요 | 미정 |
| Domitoriell idle/talk | front/side | 기본 SVG 재사용, 추가 프레임 필요 | 미정 |
| NPC talk/react | 캐릭터별 | 감정 시트 우선 | 미정 |
| Battle hit/resolve | 대상별 | 전투 시스템 설계 뒤 확정 | 미정 |

모든 숫자는 실제 시각 목업과 게임 내 캡처로 결정한다.
