# 09 — 색상 팔레트와 대비

## 1. 현재 UNDERFAIL 팔레트 관찰
기존 SVG와 UI에는 다음 경향이 있다.
- 짙은 남청/청록 배경.
- 이끼·녹청 계열 공간색.
- 낡은 금색/황토색 선과 강조.
- 따뜻한 종이색 본문 텍스트.
- 과거 학교 장면의 황토·크림 계열.
- 현재 학교 장면의 차가운 회청·안개색.

이는 현재 프로젝트 고유의 정체성으로 확장할 수 있다. [제안] 이 팔레트를 전면 교체하기보다 색의 역할을 체계화한다.

## 2. 색상 역할
| 역할 | 현재 방향 | 사용 규칙 |
|---|---|---|
| Base background | deep navy / teal | 넓은 면적, 정보와 경쟁하지 않음 |
| Primary panel | deep teal | 대화/메뉴의 배경 |
| Accent | aged gold | 선택·테두리·중요한 상호작용 |
| Text primary | warm paper | 본문과 중요 문구 |
| Text secondary | muted sage | 보조 설명 |
| Danger / tension | muted rust / red | 제한적으로 사용 |
| Memory / past | warm ochre / cream | 과거와 기억의 장면 |
| Present / institution | cold slate / teal | 현재 학교의 차가운 분위기 |

## 3. 대비 원칙
- 텍스트가 배경과 충분히 구분되어야 한다.
- 선택 상태를 색상만으로 전달하지 않는다. 커서·테두리·형태 변화도 사용.
- 피격/위험은 색 외에 움직임과 형태로 전달한다.
- 채도 높은 색은 중요한 정보에 한정한다.
- 전체 화면에 강한 그라데이션이 계속 존재하면 작은 오브젝트의 경계가 흐려질 수 있으므로 배경의 명암 폭을 관리한다.

## 4. 검증 항목
- 일반 텍스트/보조 텍스트 대비.
- 흑백 또는 저채도 화면에서 선택 상태.
- 색각 차이를 고려한 위험 표시.
- 밝은 배경 위의 캐릭터 외곽.
- 작은 브라우저 창에서 금색 선과 작은 글자 가독성.

## 5. 주의
원작의 흑백 전투 UI를 그대로 복사하지 않는다. UNDERFAIL의 청록·종이·낡은 금색 기반 색상 체계는 독자적 소재와 주제에 맞게 다듬는다.
