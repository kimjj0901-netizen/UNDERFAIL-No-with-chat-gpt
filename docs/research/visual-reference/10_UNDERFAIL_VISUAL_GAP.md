# 10 — UNDERFAIL 시각 격차 및 개선 우선순위

## 1. 확인된 격차
| 구분 | 현재 | 문제/위험 | 우선순위 |
|---|---|---|---|
| 입력 프롬프트 | Scene별 Enter/Escape/E 안내 | 같은 기능의 안내가 다름 | P0 |
| 메뉴 | 각 전투 Scene이 별도 레이아웃 | 공통 작품 UI로 인식되기 어려움 | P0 |
| 캐릭터 | SVG 공유 + 한 Scene의 Graphics 임시 초상 | 동일 캐릭터가 다르게 보임 | P1 |
| 배경 | 960×540 SVG 다수 | 세부 밀도·명암 체계가 완전히 통일됐는지 미검증 | P1 |
| 대화창 | 둥근 패널/사각 패널 혼재 | 동일 역할 UI의 선·여백 규칙이 분산 | P1 |
| 애니메이션 | Tween 중심 | 방향별 걷기/표정 시트 부족 | P2 |
| 해상도 | 16:9 | 4:3 화면 참조와 다르지만, 즉시 변경 근거는 없음 | P2 실험 |
| 전투 영역 | 각 Scene별 직접 구성 | 보드 위치/정보 위계/메뉴 규칙이 다름 | P1 |
| 사운드 | 저음량 WebAudio prototype | 최종 BGM/SFX 미완료 | P2 |

## 2. 현재 강점
- 이미 독자적인 학교풍 세계관과 캐릭터가 있다.
- 과거/현재/꽃밭/교육복지실 등 장소별 배경 에셋이 있다.
- 팔레트가 일관된 톤을 갖기 시작했다.
- 캐릭터 SVG가 각 Scene에서 재사용 가능하다.
- 전투 메뉴와 회피 패턴의 기초가 존재한다.

## 3. 개선 순서
1. 공통 입력 및 입력 도움말.
2. 같은 캐릭터의 동일 에셋 사용.
3. 전투/대화/선택 UI 공통 규격.
4. 탐험 조사 타겟과 대화 프롬프트의 시각적 명료성.
5. 캐릭터 방향별 걷기/대기 시트.
6. 전투 보드와 SOUL 가독성.
7. 4:3/16:9 동일 장면 비교 목업.
8. 최종 타일셋과 지역별 조명/색상 설계.

## 4. 채택하지 않은 성급한 변경
- 논리 해상도를 지금 당장 640×480으로 교체하지 않는다.
- 모든 SVG를 무조건 픽셀화하지 않는다.
- 메뉴 항목이나 저장/설정 기능이 실제 구현되지 않은 채로 가짜 메뉴를 추가하지 않는다.
- 원작의 검은색/흰색 UI를 그대로 복제하지 않는다.
- 모든 장면을 같은 색·패널·애니메이션으로 평준화하지 않는다.

## 5. 완료 조건
시각 변경은 실제 브라우저 스크린샷을 각 Scene에서 확보하고, 작은 창/큰 창에서 가독성과 레이아웃을 확인한 뒤에만 완료로 표시한다.

## 추가 조사 반영 — 시각 정보가 게임플레이를 설명해야 한다
- [2차 UX 분석] Undertale의 적별 화면은 캐릭터의 상태와 공격 규칙을 한 화면에서 보여줄 수 있다.
- [2차 레벨 디자인 분석] 길찾기 방향·출구의 흐름은 탐험이 자연스럽게 이어지도록 돕는다. 단, 분석자의 개인 해석이 포함되어 있다.
- [제안] UNDERFAIL의 전투 UI는 적마다 대사/표정/회피 보드 가운데 최소 한 요소가 캐릭터 성격에 맞게 달라져야 한다.
- [제안] 탐험 길은 학교의 공간 논리와 소품 배치로 안내한다. 임의의 빛 화살표만 추가해서 길을 알려 주지 않는다.
- [제안] 조사/메뉴 선택은 현재 가능한 행동을 화면에서 인식할 수 있도록 맥락적 표시를 제공한다.
