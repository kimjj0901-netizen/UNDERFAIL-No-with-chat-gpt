## 최종 에셋 승인 절차
1. 자산의 직접 제작자와 출처를 확인.
2. 상업적 이용 권리/라이선스 확인.
3. 폰트·이미지·음원·효과음별 사용 조건 기록.
4. 라이선스 문서 또는 허가 증빙 보관.
5. 미확인 자산은 최종 빌드에서 제외.

원작 스크린샷은 저작권이 확인되더라도 UNDERFAIL용 게임 자산으로 사용할 권한이 자동으로 생기지 않는다.
