# 14 — 직전 Undertale 조사 답변의 주장별 대조표

## 1. 목적

직전 답변의 내용을 빠뜨리지 않고 주제별 문서에 배분하되, 출처가 약하거나 표현이 지나치게 확정적이었던 부분은 표시한다. 이 파일은 이전 답변을 무비판적으로 정사화하지 않기 위한 변경 기록이다.

## 3. 명시적으로 수정된 주요 과장

### 3.1 “Undertale 전체 원본 코드가 공개되어 있다”

아니다. 공개된 Undertale Demo GML 자료는 데모의 일부 원본 GML이며, 정식판 전체 소스가 아니다. UndertaleModTool은 데이터 파일을 분석하는 도구이지 정식 개발자 소스 저장소가 아니다.

### 3.2 “640×480이 원작의 논리 해상도다”

이번 확인 결과로 확정할 수 있는 표현은 위키의 창 모드 스크린샷 기준이다. 게임의 내부 논리 해상도, 모든 플랫폼의 렌더링 규칙, UNDERFAIL의 필수 해상도로 일반화하지 않는다.

### 3.3 “Z/X/C 전체 키 매핑이 공식 확정됐다”

이번에 확인한 자료는 Z/Enter 타이틀 진행 및 Shift/CANCEL 관련 일부 기능이다. X, C, Ctrl, F4, ESC의 모든 역할은 정식 PC판에서 직접 확인해야 한다.

### 3.4 “피해량은 공격력에서 방어력을 단순 차감한다”

그렇게 단순화할 수 없다. 주인공이 받는 피해의 DF 감소 규칙과 적이 받는 피해의 AT/DF 상호작용, FIGHT 타이밍, 무기별 보정은 구분해야 한다. 완전한 피해 계산 함수는 확인되지 않았다.

### 3.5 “MDR이라는 변수명이 실제 원본 변수명이다”

확인하지 못했다. 위키는 Murder Level이라고 표기한다. MDR은 원본 내부 변수명으로 사용하지 않는다.

### 3.6 “모든 화면이 같은 입력으로 완전히 조작된다”

입력 언어의 공통성은 유용한 해석이지만, 키보드·컨트롤러·콘솔의 모든 입력 예외를 직접 조사하지 않았으므로 모든 기능이 동일한 키 조합을 쓴다고 확정하지 않는다.

## 4. 포함 내용의 빠짐 방지 확인

이전 답변의 모든 45개 항목은 위 표에 분류 파일 경로를 지정했다. 이 자료집은 직전 답변의 짧은 요약본이 아니라 조작, 탐험, 전투, ACT/명령, SOUL, 수치, UI, 아트, 오프닝, 캐릭터, SAVE, 현재 프로젝트 차이, 출처 및 수정 내역으로 내용을 분해한 문서 묶음이다.
