# UNDERFAIL — 오프닝 및 교육복지반 시각 방향

상태: 초기 제작 명세 / 시각 제안
대상 범위: 타이틀, 이름 입력, 과거 학교 몽타주, 폐교 문서, 현재 배정 통지서, 꽃밭, 불리 튜토리얼, 도미토리엘 구출, 교육복지반 첫 방
기술: Phaser 4.2.1 + TypeScript + Vite / 논리 해상도 960×540

## 1. 시각 원칙

- [사용자 확정] 판타지 요소가 있는 2D 스토리 게임이며, 사용자가 정한 인물·학교·사건이 창작의 중심이다.
- [기초자료 확인] 과거 합주곡 혼합고등학교는 인문계와 예체능이 공존하고 각자 꿈을 향하는 학생들을 지원한다.
- [제안] 색과 재질은 기억(따뜻한 황토·크림) → 폐교(낡은 종이·짙은 적갈색) → 현재(회청색 안개·녹슨 금속) → 꽃밭(남보라·차가운 청록) → 구출(옅은 금빛·연녹색) → 교육복지반(이끼색·낡은 목재)로 이동한다.
- [제안] 실루엣, 환경 소품, 프레이밍으로 스토리를 보여 주며 설명 텍스트가 모든 정보를 대신하지 않도록 한다.
- Undertale은 상호작용 밀도·전투 리듬·방 사이의 플레이 템포를 기능적으로 분석하는 기준이다. 원작의 문장, 맵, 픽셀 형태, 음악, 탄막·UI 그래픽은 재사용하지 않는다.

## 2. 오프닝 스토리보드

| 순서 | 스토리 기능 | 화면 구성 | 음향/전환 | 상태 |
|---|---|---|---|---|
| 0.1 | 이름 입력 | 배경을 낮게 깔고 입력란 하나를 중심에 둔다 | 사용자 입력 뒤 짧은 종이/확정음 | [기초자료 확인] + [제안] |
| 0.2-a | 먼 옛날, 꿈을 향한 학생 | 캠퍼스와 학생의 서로 다른 활동을 넓게 보여 준다 | 느린 페이드, 저음량 합성 톤 | [기초자료 확인] + [제안] |
| 0.2-b | 합주곡 혼합고등학교 | 교내 창문과 공간, 미술/음악/활동의 흔적을 보여 준다 | 따뜻한 색에서 서서히 채도 저하 | [기초자료 확인] + [제안] |
| 0.2-c | 폐교 확인서 | 단체사진·확인서·도장, 화면 끝의 손과 소매만 보인다 | 종이/도장 효과음, 잠깐의 정적 | [기초자료 확인] + [제안] |
| 0.2-d | 시간 경과와 현재 배정 | 안개 낀 학교와 배정 통지서를 함께 보여 준다 | 음색을 차갑게 전환 | [기초자료 확인] + [미정/보류] |
| 0.2-e | 학교 소문 | 학교는 멀리 두고 문서와 풍경의 간격을 남긴다 | 낮은 긴장 톤 | [기초자료 확인] + [제안] |
| 0.3 | 꽃밭과 불리 | 주인공이 바닥에서 일어나고 불리가 다가온다 | 꽃잎 움직임과 낯선 분위기 | [기초자료 확인] + [제안] |
| 0.4 | 도미토리엘 구출 | 추상 문양을 밀어내는 아크와 도미토리엘의 실루엣 | 금빛 아크, 짧은 무음 후 따뜻한 음색 | [기초자료 확인] + [제안] |

### 정사 충돌 유지

스토리 색인에는 "202X년 풍화양상 중학교"와 "고교 배정 통지서"가 함께 표기되어 있고, 워크북 및 일부 보조 문서에는 "풍화양상 고등학교"가 나온다. 어느 하나로 교정하지 않는다. 배경의 교명은 이 첫 시각 패스에서 읽을 수 없게 두거나 중립적인 건물 표현으로 처리하고, 문서의 문구 충돌은 별도 미정 항목으로 유지한다.

과거 문서의 인물은 손·소매·도장으로만 암시한다. 얼굴, 이름표, 교장임을 직접 밝히는 UI/자막을 보여 주지 않는다.

## 3. 캐릭터 1차 시트 범위

| 인물 | 화면 역할 | 1차 형상 요소 | 상태/제약 |
|---|---|---|---|
| 주인공 | 시점/조작 캐릭터 | 중립적인 교복/가방, 성별 표현을 고정하지 않는 얼굴 | [제안], 이름 외 설정 미정 |
| 불리 | 꽃밭의 기만적 첫 조우 | 어두운 외곽 실루엣, 짙은 재킷과 비대칭 자세 | [제안], 최종 목적·정체·결말 미정 |
| 도미토리엘 | 보호자/구출자 | 부드러운 녹색 계열, 긴 머리와 안정적인 자세 | 성격·보호 의도 [사용자 확정], 외형 [제안] |
| 프로깃허브 | 전투 메뉴 설명 역할 | 작고 둥근 장치/생물의 혼합 실루엣 | 역할 소재는 [기초자료 확인], 외형 [제안] |
| 전교 2등 | 교육복지반의 첫 관계 상호작용 | 책을 껴안는 닫힌 자세, 눈길을 피하는 표정 | 행동 흐름 [기초자료 확인], 외형 [제안] |

이 파일들은 최종 턴어라운드 시트가 아니다. 앞/옆/뒤, 감정별 표정, 팔·다리 분리, 걷기/달리기/대화/조사 프레임은 실제 게임 화면에서 검토한 후 추가한다.

## 4. 지역·방 디자인

### 꽃밭

- 장거리 배경은 겹겹의 언덕과 달빛으로 깊이감을 만든다.
- 전경 꽃잎은 이동하는 캐릭터 발을 가리지 않는다.
- 전투 시작 전에는 대화로 기만을 보여 주고, 전투 중에는 꽃잎 형태의 추상 문양으로 회피 규칙을 가르친다.
- 현실의 소비물/유해물이나 사용 행위의 모습을 그리지 않는다.

### 교육복지반 첫 방

- 북쪽 입구, 벽면 창문, 게시판, 중앙 퍼즐 스테이션, 프로깃허브 자리, 전교 2등 책상, 학생들의 흔적, 중앙 휴식 영역으로 시선 흐름을 만든다.
- collision은 퍼즐 장치·책상·책장·NPC 주변에 독립 영역으로 정의한다.
- 조사 가능 대상의 반경은 벽·가구 충돌 영역과 혼동되지 않도록 충분히 분리한다.
- 플레이어가 방을 가로지르며 핵심 NPC와 퍼즐을 발견하는 순서가 자연스러운지 검증한다.
- 도미토리엘은 구출 직후 첫 안내를 주는 위치에 두되, 주인공을 막아서는 대립은 해당 스토리 순서가 올 때까지 시작하지 않는다.

## 5. UI/UX

| 요소 | 시각 규칙 | 입력 |
|---|---|---|
| 타이틀 | 배경 이미지 위 제목·부제·시작 문구, 금빛 얇은 선 | Enter / Space / 클릭 |
| 이름 입력 | 중앙 입력 카드와 뚜렷한 포커스 링, 빈 값 경고 | HTML input / Enter |
| 컷신 | 아래쪽 대화판, 제목/본문/페이지 상태 분리 | Enter / Space / 클릭 |
| 조사 프롬프트 | 접근 가능한 오브젝트의 이름과 조사 키를 하단에 표시 | E |
| 전투 메뉴 | 4개 명령을 고정 정렬, 선택 강조와 설명 분리 | 방향키 / Enter / Space |
| 회피 영역 | 경계가 분명하고 패턴이 배경과 대비됨 | 방향키 / WASD |

폰트는 브라우저에 설치된 Noto Sans KR/serif 및 시스템 대체 글꼴을 지정한다. 폰트 파일은 프로젝트에 포함하지 않았다. 한국어 글리프, 작고 긴 문장, 960×540 및 작은 브라우저 화면에서 실제 검수가 필요하다.

## 6. 애니메이션과 연출

- 컷신 배경: 매우 느린 확대·페이드. 텍스트는 짧게 유지.
- 불리: 화면 가장자리에서 안으로 들어오는 진입 모션, 긴장되는 유휴 움직임.
- 주인공: 꽃밭에서 몸을 일으키는 짧은 회전/위치 보정.
- 도미토리엘/프로깃허브/전교 2등: 낮은 진폭의 유휴 움직임.
- 추상 문양: 회전과 일정한 이동, 명확한 예고.
- 구출: 금빛 아크가 서서히 나타나고 도미토리엘이 프레임 안으로 진입한다.
- 빠른 점멸, 고강도 반복 화면 흔들림, 과도한 광량은 피한다.

## 7. 사운드

- 현재 제안은 Web Audio oscillator/gain을 사용하는 저음량 합성 분위기 톤과 짧은 효과음뿐이다.
- 사용자의 클릭/키 입력 이후에만 AudioContext를 만들며, 자동 재생이 차단되어도 게임 진행은 계속되어야 한다.
- 배경음악 작곡, 캐릭터 모티프, 녹음 효과음, 음량 설정 UI는 미완료다.
- Undertale 음악을 추출/편곡하거나 유사 선율을 모사하지 않는다.

## 9. 현재 구현과 검증의 경계

- SVG 1차 자산과 Scene 연결은 코드로 작성했으나 브라우저에서 직접 플레이하지 않았다.
- 이 파일의 모든 새 디자인은 [제안]이다. 사용자 제공 정사와 충돌하면 정사가 우선한다.
- 최종 캐릭터 시트/프레임 시트, 타일셋, 조명 레이어, 실제 BGM/SFX, 최종 UI 시스템, 색각/가독성 검수는 남아 있다.
- 스토리 색인 0~1.7 원문과 창작 워크북은 계속 보호한다.
