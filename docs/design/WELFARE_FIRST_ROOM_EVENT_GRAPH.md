# 교육복지반 첫 방 — 이벤트 그래프 및 상태 규칙

상태: 구현 명세 / 첫 통합 패스
기준: 스토리 색인 0~1.7 보존 구간, CREATIVE_DECISION_WORKBOOK.md
적용 Scene: RoomScene, SecondRankEncounterScene

## 1. 실행 순서

1. 꽃밭에서 도미토리엘이 주인공을 구출한다.
2. 교육복지반에 진입하고 도미토리엘이 휴식과 자유로운 조사 가능성을 안내한다.
3. 도미토리엘에게 첫 퍼즐 안내를 받을 수 있다.
4. 첫 퍼즐은 세 표식의 순서를 관찰하고 선택하는 입력형 조우다.
5. 프로깃허브와 대화해 전투 메뉴의 역할을 배운다.
6. 프로깃허브 튜토리얼 선택을 완료하면 전교 2등이 상호작용 가능한 상태가 된다.
7. 전교 2등을 조사하면 별도 특수 조우로 이동한다.
8. FIGHT / ACT / ITEM / MERCY 선택 결과가 각각 표시된다.
9. FIGHT에서는 도미토리엘이 제지한다. ACT/MERCY에서는 전교 2등이 응답을 피한다.
10. 전교 2등은 모든 해결 경로에서 떠난다.
11. 재진입한 교육복지반에서 도미토리엘의 후속 대화가 한 번 표시된다.

## 3. 전교 2등 특수 조우 분기

| 메뉴 | 플레이어 행동 | 즉시 반응 | 공통 결과 |
|---|---|---|---|
| FIGHT | 다가가려 함 | 도미토리엘이 사이를 막아선다 | 학생은 공부하러 떠남 |
| ACT | 책 제목/좋아하는 과목/인사 선택 | 학생은 책을 끌어안고 반응을 피함 | 학생은 공부하러 떠남 |
| ITEM | 아이템 메뉴 선택 | 현재 쓸 아이템이 없다는 안내 | 메뉴로 돌아감 |
| MERCY | 물러나고 거리를 둠 | 학생은 이미 돌아설 준비를 하고 있음 | 학생은 공부하러 떠남 |

사용자 원문에서 확정한 FIGHT의 제지, 모든 메뉴 경로에서 학생의 퇴장을 보존한다. ACT 하위 선택의 구체 대사, 학생 이동 연출, 화면 UI는 [제안]이다. 현실의 위해나 무기 사용을 본뜬 연출은 하지 않는다.

## 4. 첫 퍼즐

- 환경: 중앙의 세 표식.
- 힌트: 짧게 순서대로 빛나는 표식을 관찰한다.
- 입력: 왼쪽/가운데/오른쪽 중 하나를 선택한다.
- 현재 코드 순서: 0 → 2 → 1.
- **주의:** 0→2→1은 이전 코드의 임시 데이터이며 [제안/PROTOTYPE]이다. 사용자가 제공한 스토리 원문에서 고정된 퍼즐 해답으로 간주하지 않는다.
- 성공 시: 선택한 표식이 반응하고 진행도가 증가한다.
- 실패 시: 진행도를 유지한 채 다시 선택하도록 한다.
- 퍼즐 외형과 표식 반응은 최종 아트가 아니라 초기 UI 구현이다.

## 5. 재방문 및 예외

| 테스트 | 기대 결과 |
|---|---|
| 프로깃허브 튜토리얼 전 전교 2등 근처 접근 | 상호작용 타겟이 나타나지 않음 |
| 프로깃허브 튜토리얼 후 방을 벗어나지 않고 재접근 | 전교 2등 타겟과 스프라이트 표시 |
| 전교 2등에서 FIGHT 선택 | 도미토리엘 개입 후 학생 퇴장 |
| 전교 2등에서 ACT 선택 | ACT 선택 후 학생 퇴장 |
| 전교 2등에서 ITEM 선택 | 안내 표시 후 메인 메뉴 복귀 |
| 전교 2등에서 MERCY 선택 | 물러남 반응 후 학생 퇴장 |
| 퇴장 후 RoomScene 재진입 | 학생 미표시, 도미토리엘 후속 대화 1회 |
| 후속 대화 후 다시 상호작용 | 후속 대사가 반복되지 않음 |
| 게임 새로 시작 | 관련 세션 플래그 초기화 |

## 6. 다음 구현 범위

이 문서는 1.2 특수 조우와 첫 방 기초 상호작용만 다룬다. 색인 1.3~1.7의 나머지 NPC·일반 조우·전화·휴식 공간·간식 바구니·거미 판매대·너드스타블룩 등을 완료했다고 표시하지 않는다. 해당 구간은 원본 순서를 다시 읽고 별도 이벤트 레코드로 추가한다.
