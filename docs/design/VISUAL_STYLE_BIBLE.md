# UNDERFAIL — 시각 스타일 바이블 v0.1

상태: 현재 에셋 분석 기반의 디자인 제안. 최종 아트 승인/브라우저 검수 전.
기준 화면: 960×540 (기존 기술 문서의 현재 논리 해상도)

## 1. 시각적 정체성
UNDERFAIL의 중심 이미지는 “낡고 차가운 학교 공간 안에 남아 있는 따뜻한 기억과 작은 가능성”이다.

시각 톤:
- 현재 학교: 회청·짙은 청록·안개·녹슨 금속.
- 교육복지 공간: 이끼색·낡은 목재·종이·낮은 조명.
- 과거 학교: 황토·크림·햇빛·따뜻한 녹색.
- 전투/대립: 화면 정보에 집중하도록 어두운 청록과 제한된 금색 강조.
- 선택/희망: 종이색과 낡은 금색을 제한적으로 사용.

이 방향은 기존 SVG에서 추출한 현재의 미술 경향이며, 새로 제작하는 모든 장면에 강제할 절대 정사가 아니다.

## 2. 실제 에셋에서 추출한 시작 팔레트

| 역할 | 색상 후보 | 사용 |
|---|---|---|
| Deep ink | `#101b27`, `#14272d` | 야간 배경, 깊은 그림자 |
| Main slate teal | `#233b43`, `#344b48` | 벽, 학교 구조 |
| Welfare sage | `#52655e`, `#56604f` | 교육복지실과 휴식 공간 |
| Cold fog | `#7b8075`, `#a6b4a0` | 현재 학교 외부와 유리 |
| Aged gold | `#bba77f`, `#c5b184`, `#d9c28e` | UI 외곽선·선택·중요 표식 |
| Paper | `#f1ead7`, `#d8c59c`, `#e4d4b1` | 본문·문서·기억 |
| Memory ochre | `#9b7960`, `#d2ad7c`, `#e0c69a` | 과거 학교·따뜻한 회상 |
| Muted rust | `#9b4d44`, `#a24842` | 위기/긴장, 제한적으로 사용 |

실제 에셋에서 확인한 값이며 최종 색상 시스템은 화면 캡처와 대비 테스트를 거쳐 조정한다.

## 3. 형태와 선
- 캐릭터는 작은 표시 크기에서도 머리·몸·소품 실루엣이 읽혀야 한다.
- 배경은 건축물·가구·조명으로 깊이를 만들되, 조사 오브젝트와 길을 가리지 않는다.
- UI 외곽선은 중요도에 따라 1~2px의 명확한 선을 사용한다.
- 주된 모서리 스타일은 부드러운 6~10px 곡률의 직사각 패널을 시작 규칙으로 삼는다.
- 지나치게 부드러운 카드 UI나 현대 웹 대시보드 형태는 피한다.
- 과도한 그라데이션, 광택, 그림자보다 형태와 명암의 읽힘을 우선한다.

## 4. 화면 정보 위계
### 타이틀
1. 게임명.
2. 시작 항목.
3. 조작 안내.
4. 작은 부제/세계관 문구.

### 탐험
1. 플레이어와 이동 가능한 바닥.
2. 주요 NPC/출구.
3. 조사 대상.
4. 배경 장식.

### 대화
1. 화자/표정.
2. 대사 본문.
3. 페이지 및 Confirm 안내.
4. 숨겨진 보조 정보.

### 전투
1. 적과 적의 상태.
2. 대사/상황.
3. SOUL/회피 영역(적 턴에 최우선).
4. HP/상태.
5. FIGHT/ACT/ITEM/MERCY 명령.
6. 세부 도움말.

## 5. 해상도와 스케일
- 현재 960×540/FIT/중앙 정렬을 유지한다.
- Undertale 스크린샷의 640×480은 스크린샷 게시 기준과 구별하며, 논리 해상도라고 단정하지 않는다.
- 4:3 재설계는 별도 목업/브랜치에서 같은 장면을 비교한 뒤 결정한다.
- 픽셀 기반 자산과 SVG 자산은 같은 장면에서 축소·확대 품질을 실험한 뒤 혼합 여부를 결정한다.
- 현재 SVG에 `shape-rendering`이나 nearest-neighbor 스타일을 일괄 적용하지 않는다.

## 6. 폰트와 텍스트
- 제목: serif 계열, 절제된 자간.
- 본문/대화: 한국어 Noto Sans KR 우선, 시스템 sans-serif fallback.
- 문서/기억/오프닝의 짧은 강조: Noto Serif KR 또는 serif.
- 조작 안내/상태 번호: monospace.
- 한 화면에 두 종류 이상을 넘는 폰트 역할을 남용하지 않는다.
- 한국어 긴 문장의 line-height, 줄바꿈, 잘림을 별도 QA한다.

## 7. 움직임과 효과
- 탐험 대기는 저진폭의 반복 애니메이션.
- 걷기는 발걸음과 이동 속도가 맞아야 한다.
- 대화 표정 변화는 중요한 문장에 맞춰 제한적으로 사용.
- 전투 공격은 예고 → 진행 → 종료의 읽을 수 있는 단계로 구성.
- 선택은 색상만이 아니라 테두리·커서·배경으로 표시.
- 강한 점멸, 과도한 흔들림, 불필요한 줌을 피한다.

## 8. 독자성
Undertale에서 참고하는 것은 화면 정보 위계, 작은 스프라이트의 판독성, 명령과 회피 영역의 분리, 짧은 텍스트 피드백, 정적/동적 대비다. 원작 캐릭터 디자인, 배경, 음악, UI 이미지, 공격 패턴, 대사 형태를 복제하지 않는다.

## 9. 검증 상태
- 현재 SVG 파일의 색상/크기 정적 확인: 완료.
- UI의 공통 명령 카드·선택 목록·패널 코드: 브랜치에 구현됨.
- 실제 화면/브라우저에서의 대비·텍스트·애니메이션 확인: NOT RUN.
- 최종 아트 방향 승인: 보류.
