# 조우 대화 패널 시스템

상태: 공통 패널 1차 구현 / 브라우저 검수 전

## 목적
전투와 특수 조우에서 대사·상태·명령이 같은 게임의 정보 위계로 읽히도록 공통 패널 프레임을 제공한다. 모든 화면을 동일한 위치나 크기로 강제하지 않고, 패널의 시각 언어를 공유한다.

## 공통 시각 언어
`src/ui/EncounterMenu.ts`의 `drawEncounterPanel()`:
- 짙은 청록/남청 배경.
- 낡은 금색 외곽선.
- 내부의 낮은 대비 보조선.
- 모서리를 약하게 둥글게 처리.
- Scene에서 지정한 중심점·폭·높이·depth로 배치.

## 적용 Scene
- BattleScene: 도미토리엘의 반응 대사 패널.
- BullyBattleScene: 튜토리얼 대사 패널과 명령 패널.
- SecondRankEncounterScene: 대사/명령을 포함하는 하단 패널.
- RegularEncounterScene: 일반 조우 대사/명령 영역.
- NerdstablookEncounterScene: 개별 조우 대사/명령 영역.

## 개별화 원칙
- 패널 위치와 크기는 해당 장면의 캐릭터와 전투 영역에 맞춰 설정한다.
- 패널이 공통이라고 해서 적의 표정, 배경, 대사, 공격 보드까지 같아지는 것은 아니다.
- 패널 텍스트는 각 Scene이 직접 소유한다.
- 패널은 배경 레이어이며, 선택/대사보다 높은 depth로 올라오지 않아야 한다.

## 검수 항목
- 한국어 대사가 패널 안에서 잘리는지.
- 메뉴 카드와 패널 테두리가 겹치거나 닿아 읽기 어려운지.
- 모바일/작은 창에서 패널이 화면 밖으로 나가는지.
- SOUL 보드가 나타날 때 이전 대사 패널이 겹쳐 보이지 않는지.
- 동일한 패널이 Scene 재시작 후 중복 생성되는지.

현재 상태: 코드에서 공통 패널 함수 적용. 실제 브라우저 캡처 QA는 NOT RUN.
