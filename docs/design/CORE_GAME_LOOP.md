# UNDERFAIL 핵심 플레이 루프

상태: 설계 기준 제안

## 1. 기본 흐름
```text
방 진입
  ↓
공간과 인물 파악
  ↓
이동 / 조사 / 대화
  ↓
단서·관계·아이템·퍼즐 상태 획득
  ↓
선택 / 이벤트 / 조우
  ↓
텍스트·환경·캐릭터 반응
  ↓
다음 방 / 재방문 / 새로운 선택
```

전투가 모든 방의 필수 단계는 아니다. 어떤 지역은 탐험과 대화가 중심이며, 어떤 구간은 추격·퍼즐·보스전이 중심이 될 수 있다.

## 2. 1개 조우의 기본 루프
```text
조우 진입
  ↓
상대의 상황과 태도 제시
  ↓
플레이어 명령
  ├─ FIGHT: 공격 시도 / 타이밍 판정
  ├─ ACT: 상대별 행동과 상태 변화
  ├─ ITEM: 보유 물품 사용
  └─ MERCY: 해결 가능성 / 이탈
  ↓
행동 결과 텍스트와 캐릭터 반응
  ↓
종료 조건?
  ├─ 예: 해결 / 퇴장 / 스토리 이벤트
  └─ 아니오: 상대 턴
           ↓
       회피/방어 규칙
           ↓
       피격 및 피드백
           ↓
       플레이어 턴
```

이 흐름은 기능적 모델이다. 모든 조우가 모든 명령을 사용할 필요는 없으며, 각 인물에 맞게 사용 가능 여부와 결과를 설정한다.

## 3. 반복 행동과 기억
- 같은 행동을 반복하면 적절한 경우 반복 대사가 달라진다.
- 중요한 이벤트는 플래그로 저장한다.
- 인물별 관계/태도 요소는 하나의 전역 호감도 수치로 뭉개지 않는다.
- SAVE/RESET을 세계관 인물이 인식하는지 여부는 미정/보류 상태로 둔다.

## 4. 게임 리듬 점검
각 5~10분 구간에 다음이 균형 있게 존재하는지 확인한다.
- 공간 이동 및 탐험.
- 짧은 상호작용.
- 대사 또는 단서.
- 새로운 규칙을 배우는 순간.
- 조우/퍼즐/이벤트.
- 긴장 뒤 휴식.
이 숫자는 프로토타입 점검용 제안이며 정사나 보편 법칙이 아니다.
