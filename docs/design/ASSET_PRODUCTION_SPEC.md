# UNDERFAIL 에셋 제작 규격 v0.1

상태: 제작 제안 / 완성 스프라이트 시트 아님

## 1. 현재 자산 기준
- 배경 SVG: 960×540 논리 화면.
- 플레이어 SVG 원본 크기: 120×180.
- 도미토리엘 SVG 원본 크기: 190×260.
- 일부 NPC SVG는 서로 다른 원본 크기 및 상세도를 가진다.
- 기존 캐릭터 SVG는 정적 벡터 이미지이며, 방향별 걷기/대기/표정 시트가 완성된 상태가 아니다.

## 2. 에셋 카테고리
- Opening: 타이틀/과거/현재/꽃밭.
- Rooms: 교실/복도/추후 학교 시설.
- Characters: 플레이어/NPC/적/보스.
- Items: 소지품/문서/전화/장식.
- Effects: 전투/전환/상호작용.
- UI: 패널/카드/선택 마커/상태 아이콘.

## 3. 캐릭터 제작 시트
각 캐릭터별로:
1. 실루엣 썸네일.
2. 제한 색상 팔레트.
3. 정면/후면/측면.
4. 4방향 이동.
5. idle/걷기.
6. 표정.
7. 대화 포즈.
8. 이벤트 포즈.
9. 전투 반응 포즈.
10. 실제 화면 축소 테스트.

현재 SVG의 그라데이션과 선 굵기를 무조건 최종 규격으로 삼지 않는다. 시트 제작 뒤 테스트 장면에서 비교한다.

## 4. 배경 제작 규격
- 논리 캔버스는 현재 960×540.
- 전경·중경·후경 레이어를 분리할지 장면별로 판단.
- 이동 가능한 길은 배경 장식보다 높은 판독성을 갖는다.
- NPC/조사 대상과 충돌 영역을 분리한다.
- 대화/전투 패널이 올라오는 공간에 텍스트를 방해하는 작은 디테일을 배치하지 않는다.

## 5. UI 에셋
UI 프레임은 가능한 한 공통 코드 helper로 생성하고, 꼭 필요한 이미지 자산만 SVG로 둔다. 동일 역할 UI가 Scene마다 다시 그려져 스타일이 달라지는 것을 피한다.

## 6. 라이선스
외부 참고 이미지/폰트/사운드는 최종 상업 자산에 사용하기 전에 라이선스가 확인되어야 한다. Undertale 스크린샷은 연구 참고 자료이며 게임 에셋으로 복사하지 않는다.
