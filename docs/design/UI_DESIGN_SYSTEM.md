# UNDERFAIL UI 디자인 시스템 v0.1

상태: 브랜치 구현안 / 실제 브라우저 QA 미실행

## 1. 공통 토큰
- 패널 바탕: deep teal/navy (`#09151d`, `#12262d`).
- 선택/외곽: aged gold (`#bca981`, `#d9c28e`).
- 내부 보조선: muted sage (`#64766d`).
- 주요 텍스트: paper (`#f1ead7`).
- 보조 텍스트: sage gray (`#a1a999`).

## 2. 타이틀
- 제목 중앙 정렬.
- 시작 항목은 키보드 포커스와 클릭 영역이 같은 프레임을 공유.
- 프레임은 짙은 청록 바탕과 금색 선, 왼쪽 선택 마커.
- Confirm: Z/Enter/Space.
- 포인터 클릭은 보조 수단으로 허용.
- 현재 한 개의 실제 메뉴 항목만 있으므로 가짜 메뉴 목록을 표시하지 않는다.

## 3. 대화 패널
- 공통 helper: `drawEncounterPanel()`.
- 배경은 대사와 메뉴보다 뒤에 배치.
- Scene별로 위치/폭/높이는 다를 수 있으나 외곽선·보조선·색상 역할은 동일.
- 텍스트는 대사/화자/페이지 안내 계층을 분리한다.

## 4. 전투 명령 행
- 공통 helper: `drawEncounterCommandRow()`.
- FIGHT/ACT/ITEM/MERCY 순서.
- 각 카드에 제목과 맥락적 부제를 표시.
- 선택 카드: 밝은 배경·두꺼운 금색 외곽.
- 비선택 카드: 어두운 배경·저대비 외곽.
- 키보드와 포인터 모두 같은 선택 callback을 수행.

## 5. ACT/ITEM 선택 목록
- 공통 helper: `drawEncounterChoiceList()`.
- 선택 행은 배경 틴트와 테두리, 화살표로 표시.
- 항목 텍스트는 왼쪽 정렬.
- 각 Scene은 목록 데이터와 결과 로직을 소유.
- 긴 한국어 항목은 실제 브라우저에서 줄바꿈과 세로 간격을 검증한다.

## 6. 상태와 도움말
- HP/상태는 명령 행과 시각적으로 분리.
- 현재 실행 가능한 입력만 안내.
- MENU/Ctrl은 메뉴 화면 구현 전까지 사용자 안내에 넣지 않는다.
- 기존 C 전화 호출은 계속 동작.
- 사용 불가 명령은 이유가 있으면 짧게 표시.

## 7. 접근성
- 색상만으로 상태를 구분하지 않는다.
- 키보드만으로 주요 진행이 가능해야 한다.
- 마우스 클릭도 보조로 유지한다.
- 텍스트 크기/대비/줄바꿈 검사.
- 화면 점멸과 과한 흔들림 제한.

## 8. 테스트 상태
코드 구현 및 GitHub Actions 빌드 검증과 브라우저 실기 검수는 별개다. 수용 테스트 파일의 상태를 정확히 유지한다.
