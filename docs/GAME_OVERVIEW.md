# UNDERFAIL 게임 개요

## 문서 상태

- 상태: 기획 초안
- 마지막 검토: 2026-11-05
- 상태 표기: `Canon`은 사용자 확정, `Proposal`은 승인 전 제안

## 한 줄 소개

낮은 시험 성적 때문에 낙제생반에 배정된 학생이 학교의 규칙과 사람들의 기대에 맞서, 자신이 원하는 예체능의 미래와 타인과의 관계를 선택하는 2D 픽셀 웹 RPG.

## 현재 정사(Canon)

1. 학교가 주요 배경이다.
2. 주인공은 시험 성적이 나빠 낙제생반에 배정된다.
3. 주인공은 공부보다 예체능 분야를 추구하고 싶어 한다.
4. 선생님들은 주요 보스 역할을 맡는다.
5. 학생회 임원 등 학교 구성원은 일반 적 또는 주요 적대 세력이 될 수 있다.
6. 담임 선생님은 초반 보호자·안내자 역할을 맡는다.
7. 교장 선생님은 최종 보스 역할을 맡는다.
8. 평화적인 진행에서는 관계를 형성하고 살려둔 인물들이 최종 대결에서 주인공을 돕는다.
9. 선택과 행동은 생존 여부, 관계, 사건 진행, 결말에 영향을 준다.
10. 여러 플레이 방식에 따라 루트와 엔딩이 달라진다.

## 핵심 경험

- 탐험: 교실, 복도, 특별실, 운동장 등 학교 공간을 조사하고 재방문한다.
- 대화: 상대의 사정과 규칙의 빈틈을 알아내며 갈등을 다른 방식으로 푼다.
- 전투: 턴 명령과 실시간 회피를 결합한 의지 충돌이다.
- 기억: 플레이어의 행동이 관계·평판·학교 상태로 축적되어 후반에 되돌아온다.
- 선택: 성적에 순응할지, 창작을 지킬지, 타인을 희생할지 결정한다.

## 전투 세계관 해석 (Proposal)

학교에는 규칙 위반 학생을 임시로 제압하고 시험하는 공식 절차인 **대응 심사**가 있다는 제안이다. 심사 중에는 학교의 감정·집중 시스템이 물리적 탄막처럼 나타나며, HP는 신체 생명력이 아니라 `집중력`이다. 0이 되면 사망이 아니라 심사 중단·기절·강제 귀가 등으로 처리한다. 채택 여부는 사용자 승인 대상이다.

## 기술 방향 (Proposal)

TypeScript + Vite + Phaser를 우선 후보로 삼는다. 스토리와 전투 데이터는 JSON 또는 TypeScript 데이터 모듈로 분리하고, 실행 로직은 장면·상태·이벤트 시스템으로 나눈다. 기술 선택은 프로토타입 조사 후 확정한다.

## 문서 용어

- 주인공: 이름과 성별은 플레이어가 정하거나 기본값을 둔다. 세부안은 Proposal.
- 낙제생반: 주인공이 처음 배정되는 반. 상징적 의미와 공식 명칭은 Proposal.
- 평화적 해결: 상대의 집중력을 0으로 만드는 대신 요구·감정·목표를 해소해 심사를 종료하는 방식.
