# UNDERFAIL 조사 및 설계 노트

## 문서 목적

이 문서는 대본과 시스템을 작성하기 전에 참고한 게임 디자인 원리와, 이를 UNDERFAIL에 독창적으로 변환한 결과를 기록한다. 원작의 고유명사·대사·맵·음악·그래픽·스크립트는 사용하지 않는다.

## 조사 범위와 출처

### 1. 선택의 기계적 결과

- [Undertale High-Level Game Overview](https://teemo.dev/game-design/undertale/systems/high-level-game-overview/)
- [How Undertale makes you think hard before killing monsters](https://www.gamedeveloper.com/design/how-i-undertale-i-makes-you-think-hard-before-killing-monsters)

조사 요지:

- 전투의 비폭력 선택이 모든 만남에 반복적으로 제시될 때 선택은 메뉴 장식이 아니라 핵심 게임 언어가 된다.
- 플레이어의 선택이 후속 지역, NPC 재등장, 엔딩에 누적되어야 플레이어가 자신의 행동을 기억한다.
- 폭력과 비폭력은 단순히 선/악 점수가 아니라 서로 다른 세계 상태와 정서적 결과를 만들어야 한다.

UNDERFAIL 적용:

- `대응`, `관찰`, `대화`, `행동`, `강제 제압`을 모든 주요 심사에 제공한다.
- 처치 대신 `심사 종료`, `강제 귀가`, `징계 기록`, `관계 단절`을 결과 상태로 사용한다.
- 학교의 기록과 관계를 저장해 후반 지원, 재방문 대사, 엔딩에 반영한다.
- 도덕 점수 하나로 루트를 판정하지 않고, 해결 의도·관계·기록·확보한 진실을 함께 본다.

### 2. 보스와 탄막의 학습 곡선

- [Boss Design — Design Codex](https://hayao.dev/docs/codex/system-boss-design)
- [Bullet Hell — Design Codex](https://hayao.dev/docs/codex/genre-bullet-hell)

조사 요지:

- 보스는 지금까지 배운 규칙을 시험해야 하며, 새 규칙은 한 번에 하나씩 추가한다.
- 패턴은 예고가 명확하고, 단계가 올라갈수록 속도·조합·압박을 확장한다.
- 단계 전환은 벌이 아니라 학습과 회복의 기회여야 한다.

UNDERFAIL 적용:

- 첫 보스는 이동, 안전 구역, 예고 신호만 사용하고 회전 탄막이나 화면 전환은 후반 보스로 미룬다.
- 각 패턴에는 `예고 → 실행 → 짧은 회복`의 세 구간을 둔다.
- 교사의 성격과 업무가 패턴의 모양이 된다. 칠판 오답, 시간표 격자, 도장 등은 장식이 아니라 읽을 수 있는 공격 언어다.
- 집중력 0은 사망이 아니라 심사 실패이므로 즉시 재시도·직전 선택 재검토가 가능해야 한다.

### 3. 상반된 정서의 병치

Undertale 분석 자료에서 반복적으로 확인되는 특징은 유머, 긴장, 진지한 감정이 한 시스템 안에서 교차한다는 점이다. UNDERFAIL은 이를 학교의 일상성과 제도적 압박의 대비로 변환한다.

UNDERFAIL 적용:

- 복도 방송, 급식, 수행평가 같은 익숙한 소재가 조사·퍼즐의 표면이 된다.
- 웃긴 NPC 대사는 문제를 가리지 않고, 인물의 불안이나 선택의 비용을 뒤에서 드러내는 방향으로 사용한다.
- 보스전 직전에는 농담보다 인물의 업무·책임·두려움을 선명하게 한다.

### 4. 선택의 가시성과 책임

- [How Interactive Choice Design Influences Player Emotion and Decision Behavior](https://eudl.eu/doi/10.4108/eai.22-5-2026.2365156)

조사 요지:

- 결과를 즉시 보여 주는 선택은 압박을 만들고, 늦게 돌아오는 결과는 해석과 기억을 만든다.
- 선택의 도덕적 이름보다 플레이어가 자신이 결과를 만들었다고 느끼는지가 중요하다.

UNDERFAIL 적용:

- 선택 직후에는 `기록됨`, `관계가 흔들림` 같은 최소한의 피드백만 준다.
- 자세한 결과는 재방문, 방송, 빈자리, 최종 지원 장면에서 보여 준다.
- 선택지에 “좋은 선택/나쁜 선택” 라벨을 붙이지 않는다. 대신 상황과 사람의 요구를 구체적으로 쓴다.

## 채택하지 않는 것

- 원작의 캐릭터·대사·지역·고유 시스템 명칭을 변형해 재사용하지 않는다.
- 플레이어를 몰래 벌주는 숨은 판정만으로 루트를 결정하지 않는다.
- 반사 신경만 요구하는 무예고 탄막을 사용하지 않는다.
- 학교 폭력을 사실적인 살해로 묘사하지 않는다.

## 설계 결론

UNDERFAIL의 핵심 루프는 다음과 같다.

```text
학교 공간 조사
  -> 상대의 요구와 제도적 압박 파악
  -> 심사에서 행동 선택
  -> 집중력 패턴 회피
  -> 상대 또는 기록의 상태 변화
  -> 재방문·관계·후반 지원에 누적
```

이 루프를 만족하지 않는 장면, 보스, 아이템은 대본에 넣지 않는다.
