# UNDERFAIL 전투 설계

## 설계 목표

전투는 학교에서 실제 살인을 뜻하지 않는다. 주인공과 상대가 목표를 두고 충돌하는 **대응 심사**이며, 공격과 회피는 집중력·압박·의지의 게임 표현이다. 이 해석은 `Proposal`이며 사용자 승인 후 구현한다.

## 한 턴의 흐름

1. 플레이어가 `대응`, `관찰`, `대화`, `행동`, `아이템` 중 하나를 고른다.
2. 선택에 따라 상대의 감정·규칙·공격 패턴이 변한다.
3. 상대의 심사 패턴 동안 주인공의 커서/아바타를 움직여 집중력 탄막을 피한다.
4. 패턴 종료 후 상태와 대사를 갱신한다.
5. 상대의 요구가 해소되면 `해결`, 집중력이 0이면 `중단/강제 귀가`로 종료한다.

## 용어

- `Focus`: 주인공의 집중력. 0이면 사망이 아니라 심사 실패다.
- `Pressure`: 상대가 가하는 심리적 압박. 패턴 속도·범위를 조정한다.
- `Resolve`: 평화적 해결에 필요한 상대의 미해결 목표를 해소하는 값.
- `Interrupt`: 특정 조건을 충족해 패턴을 중단하는 상태.

## 명령

- **대응**: 상대의 주장에 논리·경험으로 답한다. 효과는 보스별로 다르다.
- **관찰**: 약점, 두려움, 원하는 결과를 확인한다.
- **대화**: 관계 플래그를 올리거나 공격 패턴의 의미를 바꾼다.
- **행동**: 연습, 서류 정리, 장비 설치 등 해당 보스 전용 상호작용을 한다.
- **아이템**: 집중력 회복 또는 패턴 대응 도구를 쓴다.
- **강제 제압**: 상대의 Resolve를 크게 낮추지만 `harm_count`와 관계 손상을 남긴다.

## 보스 설계

| 보스 | 시작 이유 | 개성 패턴 | 평화 해결 조건 |
|---|---|---|---|
| 강문자 | 보충수업 이탈을 규칙 위반으로 판단 | 칠판의 오답, 시간표 격자 | 실적 압박의 출처를 찾고 대체 평가 제안 |
| 오태경 | 시설 사용과 공연을 승인하지 않음 | 조명 원뿔, 박자선, 무대 커서 | 과정을 평가하는 공연을 완성 |
| 백이안 | 주인공을 기록 위반자로 체포하려 함 | 문서 도장, 방송 파형 | 수정 기록을 함께 확인하고 책임을 나눔 |
| 차도현 | 모든 학생을 단일 기준으로 통제 | 성적표 격자, 종소리, 답안 복제 | 진실·관계·자기 선택으로 점수 체계 거부 |

## 일반 전투

일반 적은 소속과 목적에 따라 구분한다. 기록부 감시원은 서류를 지키고, 무대 관리반은 시설을 지키며, 규칙 방송 장치는 명령을 반복한다. 각 전투는 대화·관찰만으로도 해결 가능하며, 반복 제압은 해당 집단의 후속 재등장을 막을 수 있다.

## 구현 경계

현재 문서는 전투의 콘텐츠·상태 계약만 정의한다. Phaser 장면, 충돌 판정, 탄막 알고리즘, 접근성 옵션은 구현 단계에서 별도 기술 설계와 테스트 케이스로 확정한다.
