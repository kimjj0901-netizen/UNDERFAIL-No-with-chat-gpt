## Milestone 1 — 교육복지실 Vertical Slice

> 현재 상태(2026-11-26): 기존 프로토타입은 GitHub Actions TypeScript 검사와 Vite 빌드에 성공했지만, 사용자가 스토리 전개·맵·캐릭터·UI·오프닝·원작 기능 비교의 문제를 지적했다. 따라서 이전 구현을 승인된 완성본으로 보지 않고, 새 스토리 색인과 스토리 중심 마스터 프롬프트를 기준으로 재설계한다. 빌드 성공만으로 Milestone을 완료 처리하지 않는다.

**현재 목표:** 타이틀 → 이름 입력 → 과거 학교의 꿈과 폐교 몽타주 → 현재 배정 통지서와 학교 소문 → 꽃밭 → 불리의 추상 회피 튜토리얼 → 도미토리엘 구출 → 교육복지반 첫 탐험으로 시간순 시작 구간을 구축한다. 현재 시각 자산은 오리지널 SVG 제안 자산이며, 브라우저에서 보지 못했으므로 REVIEW NEEDED다.

포함 범위:

1. 타이틀과 새 게임 시작
2. 주인공 이름 입력
3. 짧은 도입 장면
4. 교육복지실 1개 방 탐험
5. 이동과 충돌
6. 조사 가능한 오브젝트 2개 이상
7. 도미토리엘과 대화 및 선택지
8. 도미토리엘과 첫 보호자 대립/전투
9. 공격·ACT·아이템·자비 메뉴의 기본 흐름
10. 단순 회피 패턴
11. 주인공의 진로 선택 의지를 반복해서 표현하는 평화 해결
12. 결과에 따른 길 열림과 프로토타입 종료 지점

범위 밖:

- 전체 루트, 일반 조우, 복잡한 인벤토리·장비
- 최종 저장/불러오기
- HP 0의 세계관적 의미
- 몰살 루트와 다중 엔딩
- 최종 아트와 완성된 사운드

임시 수치 및 대사는 별도 데이터로 표시하고 정사로 승격하지 않는다.
