# Copilot 구현 요청 — Milestone 1: 교육복지실 Vertical Slice

이 저장소에서 **Milestone 1**을 구현해줘. 목적은 게임 전체를 만드는 것이 아니라, 언더페일의 첫 구간을 실제로 플레이할 수 있게 만드는 것이다.

## 반드시 먼저 읽을 파일

아래 4개 파일을 순서대로 읽고, 그다음 현재 코드 구조를 확인해.

```text
#file: CREATIVE_DECISION_WORKBOOK.md
#file: docs/CANON_BASELINE.md
#file: docs/TECH_ARCHITECTURE.md
#file: docs/MILESTONE_1_VERTICAL_SLICE.md
```

저장소의 `.github/copilot-instructions.md`도 준수해.

## 작업 전 확인

1. 현재 브랜치와 작업 트리 상태를 확인한다.
2. `package.json`, `src/main.ts`, 현재 Scene, CSS, Vite 설정을 읽는다.
3. 현재 구현과 문서가 충돌하거나 로컬 변경이 있으면 덮어쓰지 말고 먼저 설명한다.
4. 작업할 파일과 구현 순서를 짧게 정리한 뒤 구현한다.

## 구현 목표

문서에 정의된 순서대로 아래 흐름을 연결한다.

1. BootScene에서 Title 화면으로 이동
2. 새 게임 시작
3. 한글 주인공 이름 입력 및 세션 상태 저장
4. 짧은 임시 도입부
5. 작은 교육복지실 탐험
6. 플레이어 이동 및 벽·가구 충돌
7. 최소 2개 조사 오브젝트
8. 도미토리엘과 대화 및 선택지
9. 도미토리엘과의 대립/전투 진입
10. 공격 / ACT / 아이템 / 자비 메뉴
11. 간단한 추상 탄막 회피
12. ACT 선택 누적에 따른 비폭력 해결
13. 도미토리엘이 길을 열어주고 출구가 활성화됨
14. 출구를 지나면 프로토타입 종료 화면에 도달

## 반드시 지킬 제한

- Phaser 4.2.1 + TypeScript + Vite를 유지한다.
- React, Three.js 또는 불필요한 의존성을 추가하지 않는다.
- 전체 게임, 다음 지역, 파프리카 보스, 전체 인벤토리, 모든 루트/엔딩을 구현하지 않는다.
- 최종 아트 대신 교체하기 쉬운 임시 도형·UI를 사용한다.
- 원작 Undertale의 대사, 음악, 스프라이트, 배경을 복사하지 않는다.
- 워크북에 없는 과거·비밀·인물 동기·엔딩·HP 0의 세계관적 결과를 임의로 만들지 않는다.
- ACT 반복 횟수, 이동 속도, 탄막 속도 등 미정 값은 한 곳에 모으고 `PROTOTYPE ONLY`로 표시한다.
- 저장/리셋의 세계관적 의미나 영구 루트 플래그를 이번 단계에서 구현하지 않는다.
- 문서상 이번 단계에서 터치 전용 이동 UI는 범위 밖이다. 키보드 조작을 우선 구현한다.

## 코드 구조와 품질

- 대사, 조사 대상, 전투 설정은 Scene 로직과 분리할 수 있는 데이터 구조로 둔다.
- 대화 중에는 플레이어 이동을 막는다.
- 탐험 입력과 전투 입력이 동시에 작동하지 않도록 상태를 구분한다.
- Scene 전환 후에도 주인공 이름과 필요한 진행 플래그가 유지되게 한다.
- 현재 프로젝트의 파일 구조를 존중하고 과도한 리팩터링을 하지 않는다.

## 검증

1. `npm run build`를 실행한다.
2. 개발 서버를 실행해 브라우저에서 전체 흐름을 확인한다.
3. 이름 입력(한글 포함), 이동/충돌, 조사, 대화, 전투 메뉴, 회피, ACT 해결, 종료 지점을 각각 테스트한다.
4. 실제로 테스트하지 않은 항목은 통과했다고 표시하지 않는다.
5. 오류가 생기면 수정한 뒤 다시 빌드한다.
