## 검증의 의미

- Node 단위 테스트는 상태 전이, 고정 스텝 수학, 타이밍 판정, 리듬 간격 데이터만 자동 검증한다.
- TypeScript/Vite production build는 컴파일 및 번들링을 검증한다.
- 두 검증은 실제 플레이 가능성, 화면 배치, 키보드 입력의 체감, 회피 난이도, 사운드 적합성을 보증하지 않는다.
- 브라우저 실기 QA가 끝나기 전에는 Milestone 2A를 완료 처리하지 않는다.
