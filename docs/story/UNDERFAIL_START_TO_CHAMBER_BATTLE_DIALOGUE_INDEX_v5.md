# UNDERFAIL 초반~체임버쌤 전투 개시 대화·분기 색인

> **문서 범위:** 《언더페일》의 도입부부터 교육복지실, 일반 교실·복도·가정실, 물이 흐르는 구관을 지나 체임버쌤과의 첫 정식 보스전이 실제로 시작되는 시점까지.
>
> **문서 목적:** 원작 《UNDERTALE》의 지역 순서·이벤트 작동 방식·상호작용 밀도·루트 분기·전투 리듬을 기능적으로 참고하여, 《언더페일》의 캐릭터와 세계관에 맞는 대화·사건 색인을 작성한다. 원작 대사의 복제나 문장 치환본이 아니다.
>
> **중요한 보존 규칙:** `# 7. 시간순 대화 이벤트 기록`의 **0~1.7단계는 사용자가 기존에 작성한 본문이므로 단 한 글자도 수정하지 않았다.** 이 문서에서는 그 뒤의 1.8단계부터 새로 작성했다. 앞부분의 연구 기준·용어·근거표는 현재 프로젝트 상태에 맞게 다시 정리했다.
>
> **최근 이름 변경:** 기존 문서에서 사용하던 `모델스 튜던트`는 사용자의 최신 지시에 따라 새로 작성하는 모든 구간에서 **`전교 1등`**으로 표기한다. 보존 구간 0~1.7의 기존 표현은 사용자 지시에 따라 변경하지 않는다.

## 문서 사용법

### 기록 상태

- **[사용자 확정]:** 사용자가 직접 결정한 설정 또는 이번 대화에서 명확하게 지정한 사항.
- **[기초자료 확인]:** 사용자가 작성한 워크북·제작자 개입 패널·캐릭터 자료에서 직접 확인되는 사항. 단, 초안 속 AI 제안까지 정사로 취급하지 않는다.
- **[제안]:** 원작 기능과 기존 정사를 연결하기 위해 이번 문서에서 새로 설계한 장면·대사 방향·퍼즐·일반 조우. 승인 전까지 정사가 아니다.
- **[미정/보류]:** 사용자가 명시적으로 보류했거나 아직 결정하지 않은 사항. 이 문서에서도 확정하지 않는다.
- **[원작 기능]:** Undertale에서 참고한 사건의 진행상 역할. 외형·대사·정확한 패턴을 복제한다는 뜻이 아니다.
- **[조건부]:** 이전 행동·아이템·지역 진행도·루트 플래그 등에 따라 출력 또는 출현이 달라진다.
- **[범위 밖]:** 이번 색인의 종료점 이후에 상세 기록할 내용.
- **[검증 한계]:** 원작의 모든 텍스트 노드와 모든 플랫폼별 조건을 직접 전수 실행 검증했다는 의미가 아니다.

### 분기 표기

| 용어 | 이 문서에서의 의미 | 주의 |
|---|---|---|
| **기본 진행** | 사용자가 채택한 `기본 루트`의 일반 진행을 가리키는 임시 서술어 | 원작 Neutral과 완전히 같은 루트라고 확정하지 않는다. |
| **불살 진행** | 공격·처치를 피하고 대화·행동·자비로 해결하는 진행 | 초반의 무살생만으로 완성된 후반 진실 루트가 자동 확정되는 것은 아니다. |

### 범위 경계

- 시작부터 교육복지반을 나가고, 일반 교실 구역을 통과한 뒤, 물이 흐르는 구관에서 체임버쌤과 첫 정식 보스전이 시작되는 순간까지 다룬다.
- 체임버쌤 보스전의 전체 턴 대사·승리/패배 후 장면·이후 지역의 물 건네기 이벤트는 이번 범위의 종료점 뒤에 속한다. 특히 체임버쌤에게 물을 건네는 사건은 원작의 지역 전환 기능을 고려해 **다음 Hotland 대응 구역 진입부**에서 다루는 것이 맞으며, 여기서는 앞당겨 배치하지 않는다.
- 불리의 최종 목적, 저장·재시작의 세계관 의미, HP 0의 최종 결과, 루트별 엔딩, 아스도어 정책이 학생들에게 적용되는 구체적 결과는 현재 보류 상태이므로 확정하지 않는다.

# 1. 연구 헌장 (Charter)

## 1.1 목표

- 게임 시작부터 체임버쌤과의 첫 정식 보스전 개시까지의 대화·상호작용·전투 진입 사건을 대표 진행 순서로 배열한다.
- 주요 인물뿐 아니라 일반 조우, 선택형 NPC, 퍼즐 설명, 아이템 조사, 상점, 숨은 공간, 재방문, 희귀 이벤트를 별도 항목으로 기록한다.
- 원작의 지역별 사건 기능을 이해한 뒤, 《언더페일》의 학교 판타지와 사용자 확정 캐릭터에 맞춰 독립적으로 변환한다.
- [사용자 확정]과 [제안], [미정/보류]를 분리해 Copilot이나 이후 문서 작성자가 제안을 정사로 오인하지 않게 한다.

## 1.2 Scope / Object / Subject

| 구분 | 범위 |
|---|---|
| Scope | 《언더페일》 초반부의 이야기 진행, 공간 탐험, NPC, 대화, 전투, 퍼즐, 아이템 및 루트 변화 |
| Object | 교육복지실 → 일반 교실·복도·가정실 → 물이 흐르는 구관 → 체임버쌤 전투 개시 |
| Subject | 주인공, 도미토리엘, 불리, 파프리카, SANZ, 체임버쌤, 포테이티드, 전교 1등, 전교 2등, 너드스타블룩, 빠나!! 및 이름이 정해지지 않은 일반 NPC·적 |
| 제외 | 핫랜드 대응 구역 이후의 알파이썬·머핀·크롬북 본격 진행, 폐쇄 정보실, 교장동, SANZ 최종전, 아스도어 최종전 및 엔딩 |

## 1.3 연구 방식

**Descriptive + Adaptation Design.** 원작의 대표 진행 순서와 게임플레이 기능을 기존 조사 자료 및 공개 지역 자료와 대조하고, 그 기능을 언더페일의 사용자 확정 설정에 맞게 변환한다. 원작의 실제 대사 전량을 전사하거나 매 프레임을 재현하는 연구가 아니라, 플레이 가능한 스토리 이벤트 색인을 만드는 작업이다.

## 1.4 핵심 연구 질문

- Q1. 각 지역에서 어떤 사건·대화·퍼즐·전투가 어떤 순서로 발생하는가?
- Q2. 각 이벤트의 화자·장소·선행 조건·선택지·후속 변화는 무엇인가?
- Q3. 반복 상호작용, NPC 상태, 아이템 보유, 전투에서의 행동은 어떻게 나중에 회수되는가?
- Q4. 기본·불살·몰살 진행에서 어떤 공간·대화·일반 조우·보스가 달라지는가?
- Q5. 각 보스의 전투 방식과 ACT 해결법이 해당 캐릭터의 성격·과목·목표를 어떻게 표현하는가?
- Q6. 원작의 기능을 옮기면서도 사용자 설정과 보류 항목을 침범하지 않았는가?

## 1.5 정사 판단 우선순위

1. **최신 사용자 직접 지시:** 특히 `0~1.7단계 수정 금지`, `모델스 튜던트 → 전교 1등` 변경.
2. **`CREATIVE_DECISION_WORKBOOK.md`:** 사용자가 직접 입력한 결정과 취향.
3. **`STORY_CONTROL_PANEL.md`:** `채택` 및 `보류`가 표시된 최신 개입 사항.
4. **이번 프로젝트의 직접 대화에서 사용자가 수정한 내용.**
5. **Undertale 조사 자료:** 원작 사건 순서·진행 로직·상호작용 형태를 확인하는 참고.
6. **`CHARACTER_ROLE_MAPPING.md`, `CHARACTER_DATABASE.md`, `STORY_MASTER_BIBLE.md`, v1~v4:** 사용자가 승인한 내용과 충돌하지 않는 범위에서만 보조 활용.

**충돌 처리:** 사용자가 직접 결정하지 않은 이전 AI 초안은 자동으로 정사가 되지 않는다. 보류 표시가 있는 가족 결말·저장/리셋·제압 결과·최종 루트 결과를 새 아이디어로 메우지 않는다.

## 2.3 원작에서 가져오는 것은 ‘기능’이다

- 방을 걸어 다니며 직접 조사하고, 인물에게 말을 걸며 사건을 발견하는 구조.
- 작은 방과 일반 조우 사이에 보스 및 추격 장면을 배치하는 호흡.
- 적마다 다른 ACT 해결법과 공격 패턴을 부여하는 설계.
- 이전에 한 선택을 나중에 짧은 대사·아이템 설명·NPC 태도로 되돌려주는 방식.
- 일반 진행과 비살상 진행이 상당 부분 같은 장면을 공유하되, 실제 행동 결과에 따라 작은 차이가 누적되는 구조.
- 지역 조우를 소진했을 때 일반 NPC·퍼즐·보스 상태가 변하는 경로 설계.
- 희귀 이벤트가 기본 스토리와 구분되어 별도 조건으로 작동하는 방식.

**복제하지 않는 것:** 원작의 문장·농담·음악·아트·맵 배치·고유 탄막을 그대로 옮기지 않는다. Undertale의 지역명을 교내 장소에 기계적으로 붙이는 데서 끝내지 않고, 교실의 성격과 캐릭터의 목적에 맞게 공간과 상호작용을 새로 설계한다.

# 3. 용어 및 해석 규칙

| 용어 | 의미 |
|---|---|
| 대화 이벤트 | 특정 장소·진행도·상호작용·전투 상태에서 실행되는 하나의 이벤트 묶음. 텍스트 한 줄과 같지 않다. |
| 대화 묶음 | 한 상황에서 여러 말풍선·선택 반응·내레이션이 연달아 출력되는 단위. |
| 방(Room) | 플레이어가 이동·조사·상호작용할 수 있는 개별 공간. 지도상 방 번호와 스토리 순서는 다를 수 있다. |
| 조사(Examine) | 오브젝트를 직접 살펴보는 상호작용. 최초 조사, 반복 조사, 특정 아이템 보유 시 반응이 달라질 수 있다. |
| ACT 계열 행동 | 공격 외의 행동으로 상대의 태도·전투 목적·해결 조건을 바꾸는 선택. 최종 UI 명칭은 미정일 수 있다. |
| 자비/전투 종료 | 상대가 더 싸울 의사가 없거나 특정 조건을 충족했을 때 전투를 끝내는 기능. 언더페일 UI 명칭은 미정일 수 있다. |
| 지역 조우 소진 | 그 구역의 일반 적 조우가 더 이상 나타나지 않는 상태. 원작의 숫자 조건을 그대로 이식하지 않는다. |

### 기록의 최소 단위

각 이벤트는 가능하면 다음 항목을 포함한다.

1. **장소/시점** — 맵 흐름에서 어디에 놓이는가.
2. **화자/등장** — 실제 대사 또는 행동을 맡는 인물.
3. **발생 조건** — 방 진입, 조사, 아이템, 이전 선택, 전투 상태 등.
4. **내용 요약** — 대사 원문이 아닌 장면의 정보와 감정 변화.
5. **선택/분기** — 플레이어가 무엇을 고를 수 있고 반응이 무엇을 바꾸는가.
6. **전투/퍼즐 로직** — 진입·턴 전환·해결 조건·실패 반응.
7. **후속/기억** — 이후 방·대화·아이템·관계에 남는 효과.
8. **기록 상태** — 사용자 확정인지 제안인지, 원작 기능 참고인지.

# 6. Object filter / 설계 제약

1. **이야기 흐름은 탐험 중심이다.** 주인공은 방을 이동하고, 사물을 조사하고, NPC와 대화하고, 퍼즐을 풀고, 전투를 겪으면서 학교의 성격을 알아간다. 학교 전체 공지·게시판·방송이 모든 이야기를 전달하는 방식은 사용하지 않는다.
2. **교내 공간은 판타지다.** 현실 학교의 층수나 행정 절차만으로 설명하지 않아도 된다. 물이 흐르는 구관·깊은 통로·기묘한 비밀 방 등은 각 지역의 정서와 게임플레이 기능에 맞게 배치한다.
3. **전투는 캐릭터의 목적을 표현한다.** 교사와 학생이 모두 똑같은 이유로 주인공을 공격하지 않는다. 전투 시작 이유와 비폭력 해결법은 인물별로 달라야 한다.
4. **사용자 고유의 전교 1등 전투 순서는 보존한다.** 팬클럽 유도체의 반사, 반복 후 팬클럽 해산, 필기구 최종 공격, 마지막 무력화 선언, 너드스타블룩의 만화 권유 순서를 뒤집지 않는다.
5. **전교 1등의 몰살 예외는 그 인물만의 특수 규칙이다.** 다른 적이 비공격 행동 하나만으로 몰살 진행을 자동 중단한다고 일반화하지 않는다.
6. **포테이티드는 체임버쌤을 동경한다.** 첫 만남의 동경과 후반 다리/낙하 이후의 위험 행동을 인과적으로 이어 준다. 단순히 구조당하는 소품으로 만들지 않는다.
7. **SANZ는 관찰자이지 전지적 서술자가 아니다.** 그가 직접 본 일, 남겨진 흔적, 정황 추론만 말한다. 저장·로드·리셋을 인식한다고 단정하지 않는다.
8. **루트 카운터는 언더페일 기준으로 새로 만든다.** Undertale의 Ruins 20, Snowdin 16, Waterfall 18 같은 원작 수치를 복사하지 않는다. 이 문서에서는 등장 여부와 루트 변화의 원리만 제시한다.
9. **저장 데이터와 세계관 설정을 혼동하지 않는다.** 게임 내부 플래그가 있다고 해서 캐릭터가 기억한다고 확정하지 않는다.
10. **주인공의 진로는 하나로 고정하지 않는다.** 예체능 관련 장비가 등장하더라도 특정 분야를 플레이어의 유일한 꿈으로 정하지 않는다.
11. **술·담배 표현은 불리의 기만적인 유혹 장면으로만 남긴다.** 실제 소비 방법이나 긍정적 권유로 설명하지 않는다.
12. **제안은 제안이다.** 새 NPC·공간·일반 적·대사 방향은 [제안]으로 표기하고, 사용자 승인 전 정사로 간주하지 않는다.

# 7\. 시간순 대화 이벤트 기록

## 0단계 — 시작 화면·이름 입력·오프닝

### 0.1 이름 입력

* **장소/시점:** 새 게임 시작 직후.
* **화자:** 시스템 내레이션 및 이름을 입력하는 플레이어의 선택.
* **내용 요약:** 플레이어가 인간 캐릭터의 이름을 입력한다. 이 선택은 이후 캐릭터가 플레이어를 부르는 방식과 일부 특수 이름 이벤트에 영향을 준다.
* **분기:** 일반 이름 입력이 기본. 특정 이름은 별도 경고 또는 특수 시작 상태를 유발할 수 있다. 대표적으로 `Frisk`는 일반적인 이름 설정과 다른 Hard Mode 시작 조건과 연결되므로 일반 진행과 분리해서 봐야 한다.
* **기록 상태:** 조건부.
* **누락 점검:** 이름 입력에서 사용할 수 있는 모든 금지 이름·특수 이름의 전체 목록은 별도 완전 대조를 하지 않았다. 이 문서에서는 스토리 진행에 큰 영향을 주는 알려진 특수 상태만 표시한다.

### 0.2 프롤로그 내레이션

* **장소/시점:** 인간과 괴물의 과거를 설명하는 오프닝.
* **화자:** 내레이션.
* **내용 요약(\[]는 영상 혹은 이미지적 요소 설명, {}은 실제 들어갈 글):** {먼 옛날,} {꿈을 향해 나아가는 학생이,} {그 꿈 위에 함께하는 학교가 있었다} \[인문계 - 예체능 혼합 고등학고인 '합주곡 혼합고등학교'의 학생들이 각기 꿈을 향해 다양한 미래를 향해 공부하며 웃는 모습] ->  {그러나} \[동영상 마지막 장면인 단체사진이 줌아웃되고, 그 사진이 붙어있는 '성적 부진으로 인한 폐교 확인서'에 도장을 찍는 누군가의 손, 그리고 그와 동시에 종이 위에 떨어지는 눈물 몇 방울] (손만 보이는 시점으로 인해 초반 플레이어는 알 수 없지만 이는 아스도어이기에, 그의 특징 일부분 보여야함) -> {많은 시간이 흐른 후, 202X년 풍화양상 중학교} \[풍화양상 중학교 정문, 음산함] {소문에 따르면 열등생들을 모범생으로 바꿔주는 최고의 교화소라고 한다} \[플레이어 메인 캐릭터가 풍화 양상 중학교로 배정받은 고교 배정 통지서를 뜯어서 확인하는 장면]
* **분기:** 일반 루트 공통.
* **기록 상태:** 확인.

### 0.3 불리의 첫 등장

## 3단계 — 물이 흐르는 구관 (Waterfall 기능)

**지역 기능:** 체임버쌤의 반복 추격과 강한 존재감, 포테이티드의 동경과 성장, 물길·비·빛·메아리·피아노 퍼즐, 일반 적과 선택형 NPC, 폐자재 구역 낙하, 전교 1등 전투, 너드스타블룩의 재등장, 빠나!!의 비밀 공간, 마지막 추격과 체임버쌤 보스전 개시를 담당한다.

**공간 방향:** 평범한 학교의 복도에서 갑자기 물이 흐르는 구관으로 이어진다. 낡은 복도·수로·빗물이 떨어지는 방·반사되는 결정·오래된 다리·사용하지 않는 창고가 연결되어 있다. 공간이 기묘하더라도 전교 공지나 행정 시스템이 모든 방을 통제하는 구조로 만들지 않는다. 각 방의 특성은 그 안에 사는 존재·오래된 물건·자연 현상과 상호작용을 통해 드러난다.

- **화자:** 포테이티드, 체임버쌤, 주인공.
- **내용 요약:** 포테이티드는 체임버쌤에게 인정받으려다 위험한 곳으로 뛰어들거나, 주인공을 막으려고 무리하게 다리 위로 올라온다. 원작의 Monster Kid 개입 기능처럼, 포테이티드는 주인공과 체임버쌤 사이의 갈등을 직접 바꾸는 행동을 한다.
- **핵심 인과:** 포테이티드는 단순한 구조 대상이 아니다. 처음에는 체임버쌤의 강함만을 동경했지만, 주인공과 함께 이동하고 추격의 결과를 본 뒤 자신의 선택이 필요해진다.
- **플레이어 선택:** 포테이티드를 도와주기 / 위험을 경고하기 / 개입하지 않기. 이 선택은 체임버쌤이 주인공을 바라보는 감정과 포테이티드의 후속 관계를 바꾼다.
- **루트 변형:** 몰살 진행에서는 포테이티드가 나타나지 않거나 더 두려워하는 방향으로 바뀔 수 있다. 다만 정확한 결과와 사망 처리는 미정이므로 확정하지 않는다.
- **기록 상태:** 포테이티드의 동경 관계 [사용자 확정], 후반 개입 기능은 [원작 기능] [제안].

### 3.39 체임버쌤의 마지막 추격 — 첫 정식 대면으로 연결

- **장소/시점:** 구관의 마지막 방 또는 정식 대결이 가능한 넓은 구역.
- **화자:** 체임버쌤, 주인공, 포테이티드(상황에 따라).
- **내용 요약:** 체임버쌤은 더는 주인공을 멀리서 쫓지 않고 직접 앞을 막는다. 그녀는 주인공이 학교 규칙과 구관의 위험을 무시하고 계속 나아간다고 판단한다. 주인공은 자신의 진로와 타인의 선택을 지키기 위해 이곳을 지나야 한다고 맞선다.
- **캐릭터성:** 체임버쌤은 단순한 폭력적 추격자가 아니다. 질서와 책임이 학생을 지킨다는 신념을 갖고 있으며, 그 신념을 지키기 위해 무리한 결정을 하기도 한다.

- **전투 전 대사 변화:** 포테이티드와의 관계, 다리 붕괴 장면의 행동, 일반 조우의 처리 방식, 앞선 추격에서 도망친 방법에 따라 짧은 첫 대사가 달라진다.

## 8.1 루트 용어와 조건을 구현할 때의 주의

1. **기본 루트**는 사용자가 채택한 명칭이다. 이것을 원작 Neutral과 완전히 동일한 분기 구조로 확정하지 않는다.
2. **불살 루트**는 사용자가 채택한 명칭이다. 이번 범위 안에서는 비폭력 해결과 관계를 보존하는 행동을 표시하지만, 후반 True Lab·최종 루트 완성 조건은 이 문서 범위 밖이다.
3. **몰살 진행**은 전교 1등의 특수 탈선 조건을 기술하기 위해 사용한 서술어다. 정식 이름·킬 카운터·진입 조건은 보류 상태다.
4. `강경 루트`는 현재 정사 용어로 사용하지 않는다. 사용자가 별도로 확정하기 전까지 몰살 진행과 동일시하지 않는다.
5. 특정 인물을 공격했다는 사실과 게임 세계관상 사망 판정은 구분한다. 사망·제압·귀가·징계 중 무엇이 결과인지는 별도 공통 규칙이 필요하다.
6. 플레이어가 비공격 행동을 선택했다고 해서 모든 루트가 자동으로 불살 루트로 바뀌는 것은 아니다. 전교 1등의 특수 예외만 강제 탈선 규칙을 가진다.

# 9. 몰살 진행 지역 조우와 상태 변화 색인

## 9.1 기본 원리

원작의 핵심은 단순히 적을 많이 처치하는 숫자 경쟁이 아니라, 해당 지역의 일반 조우가 더 이상 발생하지 않을 때 공간·NPC·퍼즐의 상태가 달라지고 주요 보스의 반응도 바뀐다는 점이다. 언더페일에서도 이 원리는 참고할 수 있다.

다만 원작의 Ruins·Snowdin·Waterfall의 처치 목표 숫자를 그대로 옮기지 않는다. 언더페일의 일반 조우 수, 맵 크기, 적의 생존/대피 처리 방식은 별도 설계 대상이다.

## 9.3 지역 조우 소진 시 일반 변화

- 일반 적의 랜덤 조우 빈도가 줄어들고, 최종 소진 후에는 일반적인 전투가 발생하지 않는다.
- 복도와 휴게실에서 대화하던 NPC가 자리를 비우거나 숨는다. 모든 NPC가 똑같은 방식으로 사라지지는 않으며, 개별 반응을 기록한다.
- 퍼즐에 참여하는 조력자가 없어지거나, 플레이어가 이미 알아낸 방법으로 단순하게 통과하게 될 수 있다.
- 상점과 선택형 미니게임은 영구적으로 이용 불가능해질 수 있으나, 아이템 구매 기회를 빼앗는 이유는 명확해야 한다.
- 공간이 비어 가는 것을 게시판·방송·관리 시스템이 설명하지 않는다. 발소리, 소품, 빈 의자, 닫힌 가게, 전투가 더는 시작되지 않는 사실을 통해 플레이어가 알아차리게 한다.
- SANZ의 말투는 농담에서 짧고 무거운 관찰로 바뀔 수 있다. 단, 주인공의 전체 행동을 전부 알고 있다고 주장하지 않는다.
- 전교 1등의 고유 예외가 발동하는 진행이라면, 해당 전투가 몰살 경로의 핵심 분기점이 된다.

## 9.4 구간별 주의

### 교육복지실

- 0~1.7 보존 블록에 이미 기록된 전교 2등 및 너드스타블룩 사건의 기존 표현은 변경하지 않는다.
- 그 뒤 새로 작성한 이벤트에서는 전교 1등 명칭을 사용한다.
- 도미토리엘을 처치했을 때 교육복지실 전체가 어떤 상태가 되는지는 공통 사망/제압 규칙 확정 전까지 보류한다.

### 일반 교실·가정실

- 파프리카와 일반 학생 조우는 서로 다른 카운터/관계 상태로 관리한다.
- 파프리카를 비살상으로 해결했다고 해서 모든 지역 조우가 소진된 것으로 취급하지 않는다.
- 파프리카 후속 친구 이벤트는 관계 플래그로 열리며, 불살 루트의 필수 조건인지 아직 결정하지 않는다.

### 물이 흐르는 구관

- 포테이티드의 첫 등장과 마지막 위험 장면은 별개의 플래그로 관리한다.
- 전교 1등 전투는 일반 적 조우 카운터와 별개의 고유 보스 분기다.
- 몰살 진행 중 전교 1등을 살려 보내면 **즉시 몰살 진행이 중단되는 사용자 확정 예외**를 우선 처리한다.
- 체임버쌤 전투가 시작된 시점에는 아직 전투 결과나 이후 관계 회복을 기록하지 않는다.

# 13. 결론 — 이번 범위의 진행 흐름

이번 문서가 제시하는 기본 진행은 다음과 같다.

1. **기존 0~1.7 교육복지실 구간:** 사용자가 작성한 내용을 그대로 보존한다.
2. **1.8~1.14 교육복지실 마무리:** 간식 판매대 → 도미토리엘의 생활 공간 → 회복·조사 → 출구 설득 → 반복적인 비공격 의사 표현을 통한 보스전 해결 → 불리의 행동 평가 → 초기 공간 재방문 가능성.
3. **2단계 일반 교실·복도·가정실:** SANZ의 첫 등장과 SAN 이름 기믹 → 파프리카 실습·퍼즐 → 일반 조우와 경비 퍼즐 → 파프리카 보스전 → 지역 허브와 친구 이벤트 → SANZ 재등장.
4. **3단계 물이 흐르는 구관:** 체임버쌤 첫 목격 → 포테이티드의 동경 → 반복 추격 → 메아리 꽃·수로·퍼즐·NPC·일반 적 → 전교 1등 전투 → 너드스타블룩의 개입과 재방문 → 빠나!! 숨은 마을·작은 새 왕복 지름길·어두운 미로 → 체임버쌤 추격 재개 → 포테이티드 위험 장면 → 체임버쌤과 첫 정식 보스전 개시.

이 구조는 원작의 방 단위 탐험·선택형 NPC·퍼즐·일반 조우·반복 등장·지역 후반 추격의 리듬을 참고한다. 하지만 인물·대화·전투의 목적은 학교 판타지 세계와 기존 캐릭터성에 맞게 새로 구성했다.
