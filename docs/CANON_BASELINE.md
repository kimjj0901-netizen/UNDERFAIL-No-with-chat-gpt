# UNDERFAIL 정사 기준 요약

> 상태: 워크북에서 확인되는 사용자 결정의 요약본
>
> 최우선 원본: `/CREATIVE_DECISION_WORKBOOK.md`
>
> 이 문서는 워크북을 대체하지 않는다. 문구가 다르거나 충돌하면 워크북 원문을 우선하고, 해석이 불분명하면 사용자에게 확인한다.

## 1. 작품과 중심 갈등

- 프로젝트명: UNDERFAIL / 언더페일.
- 무대: 풍화양상 고등학교.
- 학교는 현실 학교와 완전히 같지 않은 판타지적 공간이다. 교실마다 고유한 디자인이 있고 교사들은 성향에 맞는 능력을 가질 수 있다.
- 학생의 학교 배정에는 시험 점수와 생활기록이 반영된다.
- 주인공이 지키려는 핵심은 한 가지 예체능 분야 자체가 아니라, 자신이 원하는 진로와 미래를 선택할 자유다.
- 주인공은 꿈과 진로를 가로막는 학교의 구조, 학생회·선도부·교사 등과 대립할 수 있다.
- 전투는 단순한 살해 목적이 아니라 학생과 교직원이 서로의 목표를 두고 벌이는 경쟁·대립이다.

## 2. 플레이와 전투의 기본 방향

- 플레이어가 주인공의 이름을 정하고, 다양한 대화 선택을 통해 반응과 태도를 드러내는 진행 방식을 지향한다.
- 공격, 행동(ACT), 아이템, 자비/비폭력 해결, 상대 턴의 탄막 회피를 포함하는 턴 기반 전투 흐름을 참고한다.
- 장비는 이전 학생들이 남긴 물건을 중심으로 한다. 예체능 관련 물품이 중심이며, 장비별로 능력치와 공격 방식이 달라질 수 있다.
- 소모 아이템은 회복 외에도 전투 패턴 완화, 인물 관계 변화, 이스터에그, 과거 사건의 단서 등을 담당할 수 있다.
- 하나의 범용 호감도 수치보다 인물마다 별도의 관계 요소를 두는 방향을 채택했다.
- 기본 루트와 불살 루트는 채택된 방향이다. 몰살 관련 명칭·조건·결말은 별도 승인 전까지 보류한다.

## 3. 주요 인물 기준

| 인물 | 워크북에서 확인되는 기준 |
|---|---|
| 도미토리엘 | 따뜻한 교육복지실 담당자. 교감이며 교장 아스도어의 아내. 교장의 교육 방식에 반대하여 학교 입구 쪽에 교육복지실을 만들고 학생들을 보살핀다. 주인공이 떠나려는 것을 위험하다고 걱정하며 막지만, 주인공이 자기 진로를 선택하고 싶다는 의지를 반복해서 표현하면 보내주는 방향이다. |
| 파프리카 | 가정 교사. 파피루스 포지션으로 기획됨. 세부 동기·전투 해결 조건은 미정. |
| SANZ | 기술 교사. 샌즈 포지션. 워크북에는 특수 모드에서 주인공과 대적하는 역할이 기재되어 있다. |
| 디버그 스톤 | 정보 교사 2. 가스터에서 모티브를 얻은 특수 역할. 정체와 세부 기능은 미정. |
| 체임버쌤 | 수학 교사이자 학년부장. 언다인 포지션. 전투 아이디어에 별도 게임의 캐릭터에서 가져온 요소가 기재되어 있으나 세부 구현은 미정. |
| 포테이티드 | 체임버쌤을 동경하는 학생. |

| 불리 | 도미토리엘과 아스도어의 아들. 초반 튜토리얼/플라위-아스리엘 대응 역할을 구상 중이나 최종 기능은 미정. |
| 너드스타블룩 | 조용하고 내성적이며 애니메이션을 좋아하는 친구. |

| 알파이썬 | 정보 교사이자 크롬북 제작자. |
| 머핀 | 매점 아주머니. |
| 전교 1등 / 전교 2등 | 쌍둥이 캐릭터로 구상됨. 워크북에서 전교 1등의 특수 전투 아이디어가 설명되어 있다. |

### 인물명 표기 주의

- 아스도어의 한글 표기는 워크북 원문인 '스톨민트'를 우선 기록했다. 영어명과 한글 음역을 통일할지는 사용자 확인 전까지 임의 수정하지 않는다.
- 이 요약에 없는 세부 설정을 이름이나 포지션만 보고 보충하지 않는다.

## 4. 보류된 설정 — 구현 편의로 확정 금지

- 주인공의 두려움, 숨겨진 과거 및 정체성
- 학교의 오래된 비밀과 초현실 규칙의 정확한 내용
- 불리의 최종 역할 및 결말
- 저장·불러오기·재시작을 세계관 속 인물이 인식하는지 여부
- HP 0 이후의 세계관상 결과
- 몰살 루트의 정확한 진입 조건, 처치 카운터 및 제압 결과
- 전체 지역 배치와 최종 지역 순서
- 파프리카의 세부 동기, 전투 패턴 및 ACT 해결 조건
- 관계 수치의 구체적 항목과 변화량
- 최종 엔딩의 세부 내용

## 5. 첫 Vertical Slice에 사용할 수 있는 확정 재료

1. 주인공은 플레이어가 이름을 정한다.
2. 교육복지실은 도미토리엘이 학생들을 보호하는 공간이다.
3. 도미토리엘은 주인공을 걱정하고, 학교 밖으로 나가려는 선택을 위험하다고 판단해 막는다.
4. 도미토리엘은 주인공의 진로 선택 의지를 반복해서 듣고 나면 결국 보내주는 방향이다.
5. 이 대립은 적을 쓰러뜨리는 것만이 아니라, 상대의 보호 의도와 주인공의 선택권이 충돌하는 장면이다.

## 6. 정사와 제안 구분 규칙

- 위 내용과 워크북에서 명시적으로 채택한 내용만 정사로 취급한다.
- 개발상 필요한 임시 수치·대사·방 구조·색상·임시 그래픽은 반드시 `PROTOTYPE` 또는 `PROPOSAL`이라고 표시한다.
- 임시 값을 사용하더라도 추후 사용자 결정으로 쉽게 바꿀 수 있도록 데이터와 코드에 분리한다.
- 원작의 고유 대사, 문장, 리소스, 음악을 복제하지 않는다. 참고하는 것은 전투 흐름·탐험 리듬 등 추상적인 설계 원리다.
